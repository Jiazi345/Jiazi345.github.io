问题：自定义Terrian变成洋红色，使用GPUinstancing的草地和鸟群没有渲染

【已解决】

两个问题是一样的。 subshader里写了tag， pass里又写了一遍tag就会这样。

编辑器显示正常

赋值到其它物体上打包后是粉色，用来instancing则完全不显示且没有任何报错。

不正确的坐标转换也可能导致完全不渲染？总之就是哪里都没有

下面是测试历程记录。

Terrian材质变粉：

不是地形的问题，赋予到别的物体上也会变粉

也不是类型转换警告这些问题 也不是shader feature 和multi compile

解决：将HLSLINCLUDE转移到HLSLPROGRAM中 不是根本原因。解决是因为注释掉了subshader下的tag

instancing草没了的问题：编辑器里没有问题但build成exe就全部不显示

查看输出/报错：

警告：implicit truncation of vector type at...

Output value 'vert' is not completely initialized at

修改这些警告后地形还是洋红的

查看player.log：脚本Resources.Load<Material>("Land") 成功输出；

查找shader Shader.Find("Terrian/triplanar")成功输出；

禁用strip 没用

GPUinstancing脚本打印实例数量和传递到computeshader的参数，正确打印
