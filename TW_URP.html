RenderTarget:

3D场景可以被渲染到中间缓存区，或目标纹理（RenderTargetTexture），而不是帧缓冲区或后台缓冲区。

Render Texture:

被设置为摄像机的TargetTexture时，会使摄像机渲染结果渲染到RenderTexture而不是屏幕上。

在某些情况下可能会丢失：加载新关卡，进入屏幕保护模式，进出全屏。需要用IsCreate进行检测

需要使用Release进行释放，因为它不会被自动GC

RenderTexture 构造

  1. RenderTextureDescriptor 用于初始化RenderTexture的结构体

参数：Width,Height，colorFormat(颜色缓冲区格式)，depthBufferBits（深度缓冲区位数），mipCount（Mip数量）

  1. public RenderTexture (int width, int height, int depth, RenderTextureFormat.format, RenderTextureReadWirte)
  2. textureToCopy 根据已有RenderTexture创建

CommandBuffer.GetTemporaryRT:

申请一张临时RT 配合Renderidentifier使用

CommandBuffer.SetRenderTarget

添加一个激活渲染目标的指令到CommandBuffer中

指定一张RenderTexture作为渲染目标，可以直接使用，或使用GetTemporaryRT指令申请的RenderTexture的Id(int)， 也可以使用渲染周期内生成的内置(BuildIn)RenderTexture[BuildinRenderTextureType]

它们都会被转换为RenderTextureidentifier这个结构体。这个结构体描述绑定的RenderTexture如何应用到RenderTarget上，如：指定Mip, Cubemap的face，Texture3D的DepthSlice

如何申请一张RT：

初始化一个RenderTextureDescriptor;

if(renderTexture==null||!renderTexture.IsCreate())

{

//IsCreate防止已经被创建但RT为空的情况，比如加载新关卡

CoreUtils.Destory(renderTexture);

renderTexture=new RenderTexture(descriptor);

renderTexture.name="RequestRT";

}

//SetRenderTarget

ConfigureTarget(renderTexture);

初始化一个RenderTextureDescriptor;

renderTexture=RenderTexture.GetTemporary(descriptor);

renderTexture.name="RequestRT";

ConfigureTarget(renderTarget);

释放临时RT：cmd.ReleaseTemporaryRT(renderTextureID)

Release只释放显存，Destory会把Object销毁的同时把对应显存也释放掉，重新申请内存增加负担。

初始化一个RenderTextureDescriptor;

RenderTextureID=Shader.PropertyToID("Request_ID");

cmd.GetTemporaryRT(RenderTextureID, descriptor, FilterMode.Billiner);

ConfigureTarget(renderTarget);

Shader.PropertyToID获取一个全局HashID, 在材质中使用时可以直接使用名字：

SAMPLER_TEXTURE2D(Request_ID, sampler_Request_ID, uv);

CommandBuffer.GetTemporaryRT和RenderTexture.GetTemporary的区别:

RenderTexture.GetTemporary需要手动释放。
