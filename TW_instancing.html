Compute shader+GPU instancing

关于C#里绘制实例的方法们：
  • DrawMeshInstanced需要自己提供一个Matrix[]数组，来操作每个Instance的位置、旋转、缩放.一个批次最多绘制1023个对象。
  • DrawMeshInstancedIndirect则可以通过ComputeBuffer来提供这些数据。包括绘制数量也要通过ComputeBuffer提供
  • DrawMeshInstancedProcedural跟DrawMeshInstancedIndirect类似，但绘制数量可以直接通过接口提供。

大致流程：

C#部分

1 执行computeshader 更新角度

shader.Dispatch(kernelLeanGrass, groupSize, 1, 1);

2 使用Graphics.DrawMeshInstancedIndirect(mesh, 0, material, bounds, bufferWithArgs)绘制实例

需要准备mesh，materia和一个computebuffer（GPU 缓冲区包含相应的参数，指示要绘制此网格的实例数。）

3 向shader和cpmpute shader传递数据

把顶点数据储存到数组中，再把数组传递到buffer

clumpsBuffer = new ComputeBuffer(count,SIZE_GRASS_CLUMP); clumpsBuffer.SetData(clumpsArray);

#define THREADGROUPSIZE 128
#pragma kernel LeanGrass


RWTexture2D<float4> Result;


struct GrassClump
{
    float3 position;
    float lean;
    float noise;
};
RWStructuredBuffer<GrassClump> clumpsBuffer;
float time;
float maxLean;

[numthreads(THREADGROUPSIZE,1,1)]
void LeanGrass (uint3 id : SV_DispatchThreadID)
{
   GrassClump clump= clumpsBuffer[id.x];
   clump.lean=sin(time)*maxLean*clump.noise;
    clumpsBuffer[id.x]=clump;
}

在凹凸不平的表面上长草：

对每颗草，使用射线获取它们的y轴坐标。需要一个meshcollider 

void InitPos(int count,Bounds bounds)
    {
        gameObject.AddComponent<MeshCollider>();//添加collider

        clumpsArray = new GrassClump[count];

        RaycastHit hit;
        Vector3 v = new Vector3();
        v.y = bounds.center.y + bounds.extents.y;//物体空间坐标最高点
        v = transform.TransformPoint(v);//转化到世界坐标
        float castY = v.y;
        v.Set(0, 0, 0);
        v.y = bounds.center.y - bounds.extents.y;
        v = transform.TransformPoint(v);
        float minY = v.y;
        float range = castY - minY;
        castY += 10;

        int loopcount = 0;
        int index = 0;
        
        while(index<count&&loopcount<(count*10))
        {
            loopcount++;
            Vector3 pos = new Vector3(Random.value * bounds.extents.x * 2 -
               bounds.extents.x + bounds.center.x, 0,
               Random.value * bounds.extents.z * 2 -
               bounds.extents.z + bounds.center.z);
            pos = transform.TransformPoint(pos);
            pos.y = castY;
            if(Physics.Raycast(pos,Vector3.down,out hit))
            {
                pos.y = hit.point.y;
                float deltaHeight = ((pos.y - minY) / range * HeightAffect);
                if (float.IsNaN(deltaHeight)) deltaHeight = 0;//判断一下是否发生除以0
                if(Random.value>deltaHeight)
                {
                    GrassClump clump = new GrassClump(pos);
                    clumpsArray[index++] = clump;
                    Debug.Log("index" + index);
                }
            }
        }

    }

错题本：

1 #ifdef UNITY_PROCEDURAL_INSTANCING_ENABLED 字打错了。永远不执行；检查检查setBuffer中的名称和shader中是否一致

2 使用uv计算草上部分摆动下部分固定，但uv没有在顶点着色器里传递到片元着色器。在顶点输出结构里的InstanceID也需要在顶点着色器中进行赋值 否则在片元着色器中都是0

3 URP里没有unity_InstanceID，改为在顶点/片元结构体中增加uint instanceID : SV_InstanceID;在顶点着色器计算偏移

4 Graphics.DrawMeshInstancedIndirect(mesh, 0, material, bounds, argsBuffer); 这里的bounds太小会导致部分草被不正确的剔除，以及在游戏视图完全看不到草。把bounds改大：bounds = new Bounds(Vector3.zero, new Vector3(200, 200, 200));

5 除以0会导致值为float.NAN 判断一下if (float.IsNaN(deltaHeight))
